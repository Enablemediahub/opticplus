The new bundle includes the Selling Pricelist catalogue, priced/unpriced filtering, inline price editing, category row headers, prescription counts, automatic catalogue population for new prescriptions, approval queue actions, success feedback, and one branch-wide GM control for receptionist price overrides. It also lists multiple SMS phones per branch with separate refresh buttons and lets a manager label each phone. Managers can now delete a connected bank or MoMo account from its card; the account setup and reported balance are removed, SMS history and posted bank-register activity are preserved, and pending alerts are archived. No database migration is needed for either multiple phones or account removal. The existing SMS refresh columns are still required for remote inbox refreshes. After uploading, pair any phone whose token was revoked by the old one-phone-per-branch behavior; keep the currently active phone's token. Pair phones one at a time and save each token before generating the next. Use the HTTPS API URL and tokens shown on the Hostinger site, not a local 127.0.0.1 URL or token from the local development page. The APK itself does not need an update for these management changes; pending alerts retry on the phone's roughly five-minute online check, and Android may delay background work. The phone needs SMS monitoring permission for automatic incoming alerts and inbox permission for requested refreshes. The local .env is excluded.
