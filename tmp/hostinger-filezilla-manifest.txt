Database setup (not a FileZilla upload):
For Hostinger without Artisan migration access, run tmp/hostinger-package/database/manual_sql/gtbank_gmail_tables.sql in phpMyAdmin against the OpticPlus database. If Artisan migrations are available, upload the migration above and run php artisan migrate --force instead.

After uploading, set GOOGLE_CLIENT_ID, GOOGLE_CLIENT_SECRET, GOOGLE_OAUTH_REDIRECT_URI, and FRONTEND_URL in the live server .env. Use https://opticplus.bealet.com/api/v1/bank-alerts/gmail/callback as the redirect URI and register the same exact URI in the Google Cloud OAuth client. Then run php artisan config:clear. Do not upload or replace the live .env file; do not upload OAuth client secrets.

Automatic Gmail polling requires a Hostinger cron job to run php artisan schedule:run every minute from the Laravel application root. The Bank Deposits page also supports manual sync.
